## Review Focus

1. Missing `gs1Member`, invalid dates or foreign INN: unknown/reject, never show active; Task 1 adapter tests.
2. Same certificate under two shops: serialize resolved fingerprint, keep existing shop/pipeline authorization; Task 2 concurrency tests.
3. Lost response after submit/send: persist reconciliation-required state, no automatic second request; Tasks 1/3 timeout tests.
4. Invoice from another INN/thread or untrusted sender: cannot unlock payment proof; Task 3 storage/transport tests.
5. Async old-shop result, unopened mailbox and locale changes: no stale update or startup network access; Task 4 JavaFX tests.
