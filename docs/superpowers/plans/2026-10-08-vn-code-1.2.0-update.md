# VN code 1.2.0 Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution method is proposed, awaiting user selection.

**Goal:** Nâng cấp VN code 1.1.34 lên 1.2.0 theo phạm vi đã duyệt, bảo toàn định danh và dữ liệu, đưa mã/bộ cài vào Bancapnhat.

**Tech Stack:** Java 25, JavaFX, Maven, SQLite, Node contract tests, Windows jpackage và GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-08-vn-code-1.2.0-design.md`
