# UI fixture VNCode 1.4.11

Hai ảnh dùng scene 1060 × 740, theme tối, tiếng Việt, dựng từ các lớp UI VNCode trong môi trường Linux/JavaFX. Không phải ảnh thao tác seller thật hoặc ảnh Windows; không có mã KIZ, license hoặc thông tin đăng nhập của khách.

- `catalog-sync-fixture.png`: bảng xem trước dữ liệu và bước xác nhận.
- `kiz-warehouse-fixture.png`: bảng kho theo GTIN và các thao tác nhập, kiểm tra, loại/khôi phục mã chưa dùng.

Đã kiểm tra hiển thị gọn, cột bảng co theo chiều rộng, trạng thái trống đã dịch và dialog dùng CSS chung. Các kiểm thử JavaFX kiểm tra riêng đổi cửa hàng khi đang tải, bỏ kết quả cũ, consent và placeholder trên bốn ngôn ngữ. Bản dựng Windows chạy lại các kiểm thử và smoke test native hiện có.
