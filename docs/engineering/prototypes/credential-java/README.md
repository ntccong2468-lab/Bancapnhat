# Archived Java credential prototype — review only

This directory contains Java **source text for review**, with the suffix `.java.txt` so the application build does not compile it. It is not a production implementation. Do not rename it into the application's source tree, build an installer from it, run it against real data, or use its fake codec to protect real credentials. It includes incomplete, potentially unsafe runtime experiments and a test injection hook.

`src/main/.../*.java.txt` contains the experimental codec, migration, metadata reader/writer and modified application consumers from one frozen prototype. `src/test/.../*.java.txt` contains the synthetic tests. The structure preserves the original relative source paths; it is an archival review artifact and is not a standalone build. No database, logs, configuration files, target directory or actual seller credentials are included.

The file [SHA256SUMS](SHA256SUMS) records SHA-256 hashes of all 20 archived source text files. Verify from this directory with `sha256sum -c SHA256SUMS`. Nineteen files came from the same Linux/JDK 25 snapshot tested with the four test classes below. The twentieth, `PrototypeWindowsDpapiTest.java.txt`, was written afterwards and **has not been run on Windows or included in the 18 tests**.

The four classes `PrototypeMigrationTest`, `PrototypeCredentialConsumerContractTest`, `PrototypeShopConsumerTest`, and `CredentialMigrationGateFixtureTest` passed **18/18 tests**, with no skips, against synthetic credentials and SQLite fixtures on Linux. They cover a model of migration, snapshots and selected shop consumers. They do not prove that Windows DPAPI, production startup, all OMS paths or the actual application are safe. The complete test result and constraints are recorded in [the handoff](../credential-java-handoff.md).

Before runtime integration, all seven groups of blockers in the handoff require resolution: OMS ownership and every read/write path; transaction compatibility; startup and recovery; metadata lifecycle and JSON representation; Windows DPAPI and supported-platform behavior; sensitive data retention and reporting; and full integration and regression. In particular, a missing historical pipeline profile cannot currently be distinguished reliably from one that was never bound, and the existing app can associate it with a different OMS connection. Do not treat any successful synthetic test as authorization to use this prototype on a real store.
